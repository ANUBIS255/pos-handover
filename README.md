# POS Handover — سجل تسليم الماكينات

تطبيق عربي محلي لتسجيل محاضر استلام/تسليم ماكينات نقاط البيع.

## المزايا
- تسجيل القرية والتاجر ورقم الماكينة ورقم الهاتف.
- منع تكرار رقم الماكينة.
- تسجيل الشاحن والبطارية والشريحة.
- تحديد الموقع عبر GPS عند منح إذن الموقع.
- إرفاق صورة للمستند وتحويلها إلى JPG مضغوط.
- إقرار إلزامي قبل الحفظ.
- رقم محضر متسلسل وتاريخ/وقت تلقائي.
- سجل وبحث وعرض المحضر وحفظ نسخة JPG للمحضر.
- تصدير واستيراد نسخة احتياطية JSON.
- تخزين محلي والعمل دون إنترنت بعد أول تحميل.

## رفع الملفات إلى GitHub
ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع، مع الحفاظ على المسار `.github/workflows/build-apk.yml`.
يجب أن تظهر `index.html` و`package.json` في الصفحة الرئيسية للمستودع بجوار مجلد `.github`.

## بناء APK
بعد رفع الملفات إلى الفرع `main`، افتح تبويب Actions واختر Build APK. عند نجاح التشغيل، نزّل Artifact باسم `POS-Handover-APK`.
الناتج Debug APK للتجربة والتثبيت اليدوي، وليس إصدارًا إنتاجيًا موقّعًا للنشر.

## تشغيل محلي على الكمبيوتر
يتطلب Node.js 22 وJava 21 وAndroid SDK:
```bash
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

## تنبيهات مهمة
- البيانات والصور محفوظة محليًا داخل متصفح/تطبيق هذا الجهاز فقط؛ حذف بيانات التطبيق أو تغيير الجهاز قد يفقدها. استخدم تصدير النسخة الاحتياطية بانتظام.
- الصورة JPG وسيلة توثيق لكنها ليست توقيعًا إلكترونيًا ولا تمنع التعديل أو التزوير بصورة مطلقة.
- GPS يحتاج إذن الموقع وتفعيل خدمات الموقع بالجهاز.
